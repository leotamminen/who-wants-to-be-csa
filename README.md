# Who Wants to Be CSA Certified

A "Who Wants to Be a Millionaire" style quiz game for practicing the ServiceNow CSA exam. Modified from my own earlier project, [Who Wants to Be an Engineer](https://github.com/leotamminen/Who-wants-to-be-an-engineer), with the same core game engine and UI basics. Built as a fun way to practice.

## Features

- Questions grouped by CSA exam domains, with exam-style weighting
- Single answer, multiple answer and true/false questions
- Practice mode (on by default), optional music (off by default)
- Questions from MongoDB with hard coded fallback, so the game always works
- Works on desktop and mobile

## Tech

React frontend, Node backend, MongoDB, deployed on Vercel.
